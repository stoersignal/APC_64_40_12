Customizing Note / User Modes — Matrix_Maps.py format

Note Modes 1–6 and User Modes 1–6 are configured by editing Matrix_Maps.py at the repo root. The file is plain Python — open it in any text editor (avoid tabs for indentation per the file's own header comment, Matrix_Maps.py:22).

For each mode N (1 through 6), five constants control its behavior:

  • USE_STOP_ROW_N — boolean. True joins the Track Stop row to the grid as a 6th row of pads. False leaves Track Stop on its native clip-stop function.
  • IS_NOTE_MODE_N — boolean. True sends MIDI notes (Note Mode). False does not (User Mode — pads still light per PATTERN_N, but no MIDI is emitted).
  • PATTERN_N — 6 rows × 8 columns of LED color codes (legend from Matrix_Maps.py:37):
    • 0 = off
    • 1 = green
    • 2 = green blink
    • 3 = red
    • 4 = red blink
    • 5 = yellow
    • 6 = yellow blink
    • 7–127 = green
    The 6th row is the Track Stop row (used only when USE_STOP_ROW_N is True). Track Stop hardware only displays 0 = off or 1–127 = green.
  • CHANNEL_N — int 0–15 (MIDI channels 1–16). Channels 0–8 should be avoided to prevent conflict with the APC40's native mappings (per Matrix_Maps.py:50–51).
  • NOTEMAP_N — 6 rows × 8 columns of MIDI note values 0–127. Each cell maps to a MIDI note for that pad.

After editing, restart Live (or re-select the script in MIDI prefs) to load the new values. The file also contains a PAD_TRANSLATIONS array near the bottom — a 4×4 Drum Rack pad translation table (LiveAPI limit: only one drum rack at a time, max 4×4).
