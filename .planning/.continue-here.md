## Decisions (this task)

- AutoFilter detection accepts both `'AutoFilter'` (Live 9/10) and `'AutoFilter2'` (Live 11+). Same param names → same code path. `FILTER_DEVICES` (used by EQ Smart Control) also gets the AutoFilter2 entry.
- Filter-type-aware encoders resolved by `Filter Type.value_items` label, not enum index — robust across Live builds.
- `'LFO On'` doesn't exist on AutoFilter2; replaced Send A with `'S/C On'`. `'Sidechain Mix'` is continuous so doesn't fit a toggle; replaced Send C with `'Soft Clip On'`.

## Critical Anti-Patterns (project-wide, discovered this session)

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|-----------|
| `parameter.is_enabled` lies | Live keeps `is_enabled = True` even on UI-greyed-out controls. Don't use it to detect "this control is currently meaningful". | advisory | Read the upstream value (filter type, mode index, etc.) directly. |
| Plain `ButtonElement` has no `set_enabled` / `set_on_off_values` | Only `ConfigurableButtonElement` has those. Calling on plain buttons throws AttributeError. | advisory | Check the button's class at construction site (`APC_64_40_9.py`). Plain `ButtonElement` for Scene Launch / Bank Select / Stop All Clips. `ConfigurableButtonElement` for Track Stop / matrix pads / `_global_bank_buttons`. |
| `strip.set_send_controls` fights for encoders 1/2/3 | Default Smart Control wiring rebinds encoders 1/2/3 to Send A/B/C. If a sub-mode (Eq8, ChannelEq, AutoFilter) needs those encoders, pass `None` for sends. | advisory | See `EncoderEQComponent._update_controls_and_buttons` `eq_class == 'Eq8'` branch (commit `c599503`). |
| `clip_slot.canonical_parent` returns Scene on Live 12 | Not Track. Scenes have no `devices`. | advisory | Use `song.visible_tracks[session.track_offset() + i]` (proven in `SpecialMixerComponent.py:46-47`). |
| Live 11+ rebuilt class names | `'AutoFilter'` is Live 9/10; Live 11+ uses `'AutoFilter2'`. Other devices may have similar version splits. | advisory | When matching device classes, accept both old and new names. |
