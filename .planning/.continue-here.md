## Decisions (this task)

- **Display API:** transient `Application.show_message(text)`. Live's
  standard notification — auto-fades, replaces previous text. NOT
  `set_status_text` (would conflict with Live's own status messages).
- **Centralized `StatusBarMessenger.py` helper.** Constructor
  dependency-injected via `messenger=None` kwarg on every component.
  Default-None means each task lands as an independent atomic commit.
- **Hardware-side value listeners (NOT `param.add_value_listener`)** for
  parameter-value messages. Param listeners fire on Live-UI changes too;
  hardware-side fires only when MIDI arrives from the APC40 — matches
  user intent ("when I turn the cutoff"). Resolved via the
  `make_hardware_value_callback` factory.
- **Throttle:** 50ms per `id(param)` debounce + 200ms identical-text
  dedup + 2s cold-start silence. Caps message rate at ~20Hz under rapid
  encoder twirl; suppresses bootup setup-noise.
- **Pan16DeviceComponent OUT OF SCOPE** — the 16-macro Pan-mode
  encoders use a separate listener pattern that doesn't share the
  factory. Documented as Phase 6 follow-up TODO in user manual.

## If anything fails

Same 4-round debug pattern as quick-260504-k6p / quick-260504-m2x:

1. **Verify the listener fires** — every show_* method already passes
   through to `_emit` which is fail-quiet wrapped. If the message
   doesn't appear, the listener isn't firing OR `application().show_message`
   raised silently. Add a `print()` or `log_message()` in `_emit` to
   prove it's reaching that point.
2. **Verify the param has `str_for_value`** — some Live builds /
   custom devices don't expose it. Falls back to `repr(value)` per
   D-05. If the formatted string looks wrong, this is the cause.
3. **Verify cold-start silence isn't suppressing legit messages** —
   the 2s window starts at messenger construction. If Live takes >2s
   to deploy state, a legit early message could be eaten. The fix is
   to extend the window OR to switch to a "after first non-init event"
   gate.
4. **Verify the hardware listener strategy** — if Live-UI moves are
   ALSO messaging, we accidentally hooked param listeners somewhere.
   Grep for `add_value_listener` calls touching `param` directly (vs
   the encoder/fader element).

## Critical Anti-Patterns (project-wide, reinforced this session)

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|-----------|
| Silent failure modes | `connect_to(None)`, `get_parameter_by_name()` miss, `turn_on()` last-sent cache short-circuit, `param.add_value_listener` on a ghost ref — all fail invisibly. | advisory | Instrument with `log_message` BEFORE assuming success. The diagnostic dump pattern (one-shot Log.txt of param list / value_items) caught the LFO Frequency miss + 6-vs-4 LFO mode mismatch + Stop All Clips hardware-only LED in one round each. |
| Hardware addressability is firmware-version-dependent | Some APC40 buttons accept MIDI feedback (Mute/Solo notes 49/50, Detail View note 62), others (transport-style: Stop All Clips, Play, etc.) ignore feedback regardless of velocity / force / re-assertion. | advisory | When designing an indicator, verify the LED responds to Live's OWN writes during normal use. If not, it's hardware-only and no script change can address it. Switch to a known-working button. |
| Enum-driven param routing without value_items dump | Guessing prefix matches for enum mode labels (Hz / S / 4 / 16) silently mis-binds when the actual labels are different (Rate / Time / Synced / Triplet / Dotted / Sixteenth). | advisory | Always dump `param.value_items` via Log.txt diagnostic BEFORE writing the lookup table. Cost: one log line. Saves multiple round-trip UAT cycles. |
| `parameter.is_enabled` lies | Live keeps `is_enabled=True` even on UI-greyed-out controls. | advisory | Read upstream values directly (filter type, mode index, etc.). |
| Plain `ButtonElement` has no `set_on_off_values` | Only `ConfigurableButtonElement` has it. Calling on plain buttons raises AttributeError. | advisory | Check the button's class at construction site (`APC_64_40_9.py`). Use `send_value(velocity, force=True)` directly to bypass — works on both classes. |
| `clip_slot.canonical_parent` returns Scene on Live 12 | Not Track. Scenes have no `devices`. | advisory | Use `song.visible_tracks[session.track_offset() + i]`. |
| `strip.set_send_controls` claims encoders 1/2/3 | Default Smart Control wiring rebinds encoders 1/2/3 to Send A/B/C. Sub-modes that need those encoders must pass `None` for sends. | advisory | See `EncoderEQComponent._update_controls_and_buttons` `eq_class == 'Eq8'` branch. |
