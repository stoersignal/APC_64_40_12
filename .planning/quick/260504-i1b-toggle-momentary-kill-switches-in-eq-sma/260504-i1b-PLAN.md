# Quick Task 260504-i1b — Toggle / Momentary kill switches (EQ Smart Control mode)

## Goal

The three EQ kill buttons (bass / mids / highs in Filter EQ 3, or the equivalent first three cuts on Eq8 / Audio Effect Rack) gain the same dual-behavior the v1.0 Solo / Mute buttons already have:

- **Short press (< 400 ms)** — toggle the kill on / off (current behavior, preserved).
- **Long press (≥ 400 ms)** — momentary: the kill engages on press-down and reverts to the previous state on release. Hold to duck a band, release to bring it back.

Outside TRACK CONTROL MODE 3, kill-button behavior is unchanged (the buttons are normal Pan / Send-A / Send-B / Send-C bank selectors).

## Behavior contract

For each of the three kill buttons (cut index 0 / 1 / 2):

- **Press (value != 0)**:
  - If `_ignore_cut_buttons` is true: do nothing (safety net used when leaving the mode mid-press).
  - Else read the current parameter value, store it in `_cut_state_before_press[i]`.
  - Toggle the parameter to its opposite (`0 ↔ 1`, scaled by 127 for `AudioEffectGroupDevice`) — same code path as today.
  - Set `_cut_ticks_delay[i] = LONG_PRESS_DELAY` (4 ticks).
- **Timer tick**: for every `i`, if `_cut_ticks_delay[i] > -1`, decrement; when it hits 0 set `_cut_momentary_active[i] = True`.
- **Release (value == 0)**:
  - If `_cut_momentary_active[i]` is True, write `_cut_state_before_press[i]` back to the parameter.
  - Reset `_cut_ticks_delay[i] = -1` and `_cut_momentary_active[i] = False`.

State-array size matches the wired button count. `set_cut_buttons(buttons)` reverts any active momentary hold on the OUTGOING buttons before resizing.

`disconnect()` reverts any active momentary hold and unregisters the timer.

4. Override `_cut_value(value, sender)` to branch press / release:
   ```python
   def _cut_value(self, value, sender):
       assert (sender in self._cut_buttons)
       assert (value in range(128))
       if self._ignore_cut_buttons:
           return
       if not (self.is_enabled() and self._device is not None):
           return
       device_dict = EQ_DEVICES[self._device.class_name]
       if 'Cuts' not in device_dict:
           return
       cut_names = device_dict['Cuts']
       index = list(self._cut_buttons).index(sender)
       if index >= len(cut_names) or index >= len(self._cut_ticks_delay):
           return
       parameter = get_parameter_by_name(self._device, cut_names[index])
       if parameter is None:
           return
       if value != 0:
           # Press — capture, toggle, start countdown.
           try:
               self._cut_state_before_press[index] = float(parameter.value)
           except Exception:
               return
           if parameter.value > 0:
               parameter.value = 0
           else:
               parameter.value = 1
           if self._device.class_name == 'AudioEffectGroupDevice':
               parameter.value = parameter.value * 127
           self._cut_ticks_delay[index] = LONG_PRESS_DELAY
       else:
           # Release — if momentary engaged during hold, revert.
           if self._cut_momentary_active[index]:
               try:
                   parameter.value = self._cut_state_before_press[index]
               except Exception:
                   pass
               self._cut_momentary_active[index] = False
           self._cut_ticks_delay[index] = -1
   ```

5. Add `_on_timer(self)`:
   ```python
   def _on_timer(self):
       if not self.is_enabled():
           return
       for i in range(len(self._cut_ticks_delay)):
           if self._cut_ticks_delay[i] > -1:
               if self._cut_ticks_delay[i] == 0:
                   self._cut_momentary_active[i] = True
               self._cut_ticks_delay[i] -= 1
   ```

6. Extend `disconnect` (if no override exists yet, add one that delegates to `TrackEQComponent.disconnect`):
   ```python
   def disconnect(self):
       # Revert any in-flight momentary holds before tearing down listeners.
       if self._cut_buttons is not None and self._device is not None:
           device_dict = EQ_DEVICES.get(self._device.class_name, {})
           cut_names = device_dict.get('Cuts', [])
           for i in range(len(self._cut_buttons)):
               if i < len(self._cut_momentary_active) and self._cut_momentary_active[i]:
                   if i < len(cut_names):
                       parameter = get_parameter_by_name(self._device, cut_names[i])
                       if parameter is not None:
                           try:
                               parameter.value = self._cut_state_before_press[i]
                           except Exception:
                               pass
                       self._cut_momentary_active[i] = False
       try:
           self._unregister_timer_callback(self._on_timer)
       except Exception:
           pass
       TrackEQComponent.disconnect(self)
   ```
