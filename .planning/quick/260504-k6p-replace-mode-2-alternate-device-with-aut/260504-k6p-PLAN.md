# Quick Task 260504-k6p — AutoFilter Mode (Shift + Send A)

Replace TRACK CONTROL MODE 2 (Shift + Send A — currently the "Alternate Device Mode") with a focused **Auto Filter Mode** that maps the 8 Track Control encoders and 4 bank buttons to AutoFilter parameters, mirroring how MODE 3 maps to EQ devices.

## Encoder + button layout

```
Top row    [0=Drive    ][1=Env Atk  ][2=Env Rel  ][3=LFO Rate ]
Bottom row [4=Frequency][5=Resonance][6=Env Amt  ][7=LFO Amt  ]
Bank btns  [Pan=Slope↻ ][SndA=LFO   ][SndB=Type↻ ][SndC=Sidech]
```

Pan / Send B step their respective enum parameters (Filter Slope, Filter Type) one step per press, wrapping at the parameter's `max`. Send A / Send C toggle their boolean parameters (LFO On, Sidechain Mix). Bank-button LEDs light when their parameter is non-zero.

## Implementation

- New file `EncoderAutoFilterComponent.py` — `EncoderAutoFilterComponent(ControlSurfaceComponent)`. API surface compatible with the old `EncoderDeviceComponent`: `set_enabled`, `set_controls_and_buttons(controls, buttons)`, `set_lock_button(btn)` (no-op shim), `_ignore_buttons` attribute (consumed by mode 3 / `ShiftableEncoderSelectorComponent`).
- `APC_64_40_9.py` — instantiate `EncoderAutoFilterComponent` instead of `EncoderDeviceComponent`. Variable name `_encoder_device_modes` retained (referenced by `EncoderUserModesComponent` / `ShiftableEncoderSelectorComponent`); only the underlying class changes.
- `EncoderUserModesComponent.py` — drop the now-broken `_alt_device.*` cleanup block in `_set_modes`; the new component self-cleans via `on_enabled_changed`.
- Diagnostic: one-shot `[AutoFilter]` Log.txt dump on first detection — verifies the parameter-name guesses (`'Drive'`, `'Env. Attack'`, `'Filter Slope'`, `'LFO On'`, etc.) in one UAT round if anything's off.

## Tasks

### Task 1 — Create EncoderAutoFilterComponent

**Files:** `EncoderAutoFilterComponent.py` (new)

Implements the parallel-to-EncoderEQComponent shape: `_detect_autofilter` walks `track.devices` for the last `class_name == 'AutoFilter'`. `_update_controls_and_buttons` releases all 8 encoders, then connects them per `ENCODER_MAP`. Bank buttons get value listeners (toggle / cycle handlers per `BUTTON_MAP`) and per-parameter LED listeners. `_teardown_bindings` removes everything cleanly.

### Task 2 — Wire it into APC_64_40_9

## Out of scope

- Toggle/momentary dual behavior on the bank buttons (LFO/Sidechain are simple toggles; user can tap-vs-hold isn't asked for).
- Real-time re-detection if AutoFilter is added/removed mid-mode without a track-selection change. Track-selection updates re-trigger detection via `on_selected_track_changed`.
- LED for Pan / Send B (cycling enum buttons): they light when value > 0 (i.e. anything other than the lowest enum value). A "color = enum value" multi-state LED would be nicer but APC40 buttons only have on/off.
- Removing `EncoderDeviceComponent.py` from the codebase — kept around in case it's useful later (no longer instantiated, just unused).
