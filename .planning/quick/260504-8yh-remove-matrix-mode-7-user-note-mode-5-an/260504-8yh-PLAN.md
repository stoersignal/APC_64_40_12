# Quick Task 260504-8yh — Replace Matrix Mode 7 (USER/NOTE MODE 5) with Global Variations Mode

## Goal

Slot 6 of the matrix-mode selector becomes a **per-track variations cockpit**: each grid column shows the variations of the first rack-with-variations on its track. Bank Select Up/Down scrolls the grid globally; Scene Launch buttons fire the row across all tracks at once. The slot's previous identity (User/Note Mode 5) is removed end-to-end.

## Behavior contract

When the matrix-mode selector enters slot 6 ("Global Variations"):

- **Each column 0..7** is bound to one visible track at mode entry. For that track, the script walks `track.devices` in order and picks the **first device with `variation_count > 0`** (the column's "rack"). Tracks without such a device leave the column dark.
- **Visible 5×8 grid** — within each column, rows show variation indices `bank_offset .. bank_offset + 4`:
  - **Green pad** when `i = bank_offset + row < column_rack.variation_count` (slot stored).
  - **Red pad** when `i == column_rack.selected_variation_index` (currently selected, supersedes green).
  - **Off pad** otherwise (no rack on this column, or row beyond stored variations).
  - Press a green/red pad → set `column_rack.selected_variation_index = bank_offset + row; recall_selected_variation()`. Empty-pad presses are no-ops.
- **Scene Launch row (5 buttons, scenes 0..4)** = global variation triggers:
  - Press scene `R` → for each column 0..7 that has a rack and a stored variation at index `bank_offset + R`, set `selected_variation_index = bank_offset + R; recall_selected_variation()`. Tracks without that variation are silently skipped.
  - Scene LED is green if AT LEAST ONE column has a stored variation at row R, else off. (Cheap heuristic — keeps the row visually informative without needing per-column LED math on the scene strip.)
- **Bank Select Up/Down** = global scroll:
  - Down (`_down_button`, note 95) → `bank_offset += 1` and refresh.
  - Up (`_up_button`, note 94) → `bank_offset = max(0, bank_offset - 1)` and refresh.
  - Scroll is unconstrained at the top end (allowed to go beyond `max(variation_counts) - 5`); over-scrolled rows simply show dark cells. Ceiling guard would force per-column normalisation, which we explicitly chose against.
- **Track Stop row (8 buttons)** — left at default clip-stop wiring (`_session.set_stop_track_clip_buttons` from the standard pre-mode setup).
- **No rack on any column** — entire grid + scene strip dark, all presses are no-ops.
- **Refresh moments** — mode entry; bank scroll; pad press (after recall); scene press (after recall round); `track.add_devices_listener` fires (device added/removed on a column's track); `device.add_variation_count_listener` fires (store/delete on a column's rack); `device.add_selected_variation_index_listener` fires (recall via Nudge or Live UI).

     - `_global_var_refresh_leds()`.

### Global Variations Mode (Per-Track Rack Variations)
* **How to access**: Hold **SHIFT** and press **Track Select 7** to enter Matrix Mode 7 — now `Global Variations Mode` (replaces the former User/Note Mode 5).

* **Scroll past 5 variations**: Use **Bank Select ↑ / ↓** to slide the visible window up/down. The same offset is applied to every column.
* **Track Stop row**: keeps its default clip-stop function in this mode.
* **Storing variations**: still on **Shift + Tap Tempo** (it acts on the appointed device, not necessarily this column's rack — appoint the rack first via the blue-hand icon or Shift + Nudge Back).
