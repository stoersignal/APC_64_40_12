# Quick Task 260504-5j0 — Replace Matrix Mode 8 (USER/NOTE MODE 6) with Variations Mode

## Goal

The 8th slot in the Matrix-Mode selector becomes a Rack Macro Variations control surface for the currently appointed device. The slot's previous identity (User/Note Mode 6) is removed end-to-end (code + Matrix_Maps + docs).

## Behavior contract

When the matrix-mode selector enters slot 7 (the new "Variations" mode):

- **Main 5×8 clip grid (40 pads)** — each pad maps 1:1 to a variation index (row-major: row 0 col 0 = index 0; row 4 col 7 = index 39).
  - LED is **green** (color code 1) when `pad_index < device.variation_count` (slot is stored).
  - LED is **red** (color code 3) on `pad_index == device.selected_variation_index` (currently selected; supersedes green).
  - LED is **off** otherwise (empty slot, or no appointed device, or appointed device is not a Rack).
  - Press → set `device.selected_variation_index = pad_index`, then `device.recall_selected_variation()`. No-op if pad index ≥ `variation_count` (can't recall an empty slot).

- **Track-Stop row, leftmost button (col 0)** — "Store new variation".
  - LED is **yellow** (color code 5) whenever a Rack-capable appointed device is present; off otherwise.
  - Press → `device.store_variation()` (appends a new variation; Live decides the new index). After the call, repaint the grid.

- **Track-Stop row, columns 1–7** — off and inactive in this mode (reserved for future use).

- **No appointed device / non-Rack device** — all 48 buttons (40 pads + 8 stop) go off; presses are no-ops. Treat absence-of-`variation_count`-attribute as "non-Rack" (mirrors ShiftableTransportComponent.py:140 / :154 / :170 hasattr guards).

- **Channel** — Variations Mode does NOT remap MIDI channel (unlike `_set_note_mode`). The pads stay on their default APC40 channel; Live never sees note output, since pads are consumed by the script's value listener.

- **Refresh moments** — repaint LEDs on: mode entry; every pad press (after recall); store-button press; appointed-device-change (if listener available).
