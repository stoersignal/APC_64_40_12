# Quick Task 260504-jt9 — Eq8 gain ↔ Q swap (bands 1 & 8)

## Goal

In TRACK CONTROL MODE 3 with EQ Eight, when band 1 or band 8 has its filter type set to a shape that has no gain (LP / HP / Notch), the matching gain encoder (Low Gain on encoder 5, High Gain on encoder 7) is automatically re-bound to that band's Q (resonance) parameter. The swap re-evaluates in real time when the user changes the filter type from Live's UI.

## Behavior contract

For each tracked band ∈ {1, 8}, encoder index ∈ {5, 7}:

- Setup-time: read `parameter.is_enabled` on `'<n> Gain A'`.
  - True → `release_parameter()` then `connect_to(<n> Gain A)` — restores gain binding even if the encoder was previously in Q mode.
  - False → `release_parameter()` then `connect_to(<n> Q A)` — encoder drives Q instead.
- The same logic re-runs whenever the filter-type parameter (`'<n> Filter Type A'`) fires its value listener.
- Band 2 (Mid Gain on encoder 6) is **never** swapped to Q.
- Other devices (FilterEQ3 / ChannelEq / AEG) are unaffected.
- Listeners are cleanly attached on `_setup_eq8_extras` and detached on `_teardown_eq8_extras` so switching tracks doesn't leave dangling listeners.
