## High-level approach (read once before starting Task 1)

**Six implementation pillars:**

1. **One messenger, dependency-injected.** Per D-03, NO singleton. The messenger is instantiated once in `APC_64_40_9.__init__` and passed to every component constructor that emits messages. New constructor parameters are added at the END of each `__init__` signature with a `messenger=None` default — keeps old call sites and unit tests working.

2. **Mode events fire on TRANSITIONS only.** Every mode message fires inside the existing `_engage` / `_disengage` / `_set_modes` / `set_mode` paths — places that ALREADY run once per real transition. NEVER fire from button value listeners directly (those see press AND release events).

3. **Param-value messages come from HARDWARE listeners, NOT param listeners.** The cleanest filter for "user moved a knob on the APC40" is the EncoderElement / SliderElement value listener, which fires only on incoming MIDI. The param-listener variant fires on ALL param changes (Live UI moves + automation playback + hardware) — too noisy. Strategy: when a control is `connect_to(param)`'d, ALSO add a hardware-control value listener that reads `param.str_for_value(param.value)` at fire-time.

4. **Throttle in the messenger, not at every call site.** Per D-04: 50ms debounce keyed by `id(param)` for `show_param`; mode events bypass throttling. Plus identical-text dedup (gotcha #6) and 2s cold-start silence (gotcha #7).

5. **Listener bookkeeping mirrors DrumRackModeComponent.** Every `add_value_listener` registers `(target, callback)` in a per-component list; `disconnect()` / re-bind paths iterate that list with try/except removal. NEVER call `remove_value_listener` without a matching `add` having succeeded.

6. **Partial-rollout safety.** Each task lands as one atomic commit. A `messenger=None` default in every new constructor parameter means landing tasks 1+2 alone (helper + APC_64_40_9 instantiation) is a no-op functionally; landing 1+2+3 (Drum Rack only) leaves AutoFilter / EQ / Matrix / mixer silently un-messaged but still working. UAT can verify category-by-category.

Internal contract:
- `_emit(text)` — single chokepoint. Wraps `parent.application().show_message(text)` in try/except `Exception` (gotcha: handshake may not be complete; `application()` can raise on cold boot). Records the emitted text in `_last_text`.
- Cold-start gate: if `_now_ms() - _construct_ms < COLD_START_QUIET_MS`, return without emitting (applies to all three public methods).
- Identical-text dedup: if the about-to-emit text equals `_last_text`, return without emitting. Reset `_last_text` to `None` after `THROTTLE_MS * 4 = 200ms` of inactivity so a deliberate re-display of the same text after a pause still works (use timestamp tracking; do NOT keep dedup forever).
- `show_param` throttle: keyed on `id(param)` passed via `param_id`. If `param_id is None`, skip the throttle (caller signalled a one-off).

Use `time.time() * 1000.0` for `_now_ms()`. Wrap every public method in a top-level try/except so a misbehaving parent (e.g. `application()` returning None during teardown) NEVER crashes the caller — fail-quiet is the project idiom.

```python
def make_hardware_value_callback(self, param_provider, name_provider=None):
    """Build a value-listener callback to attach to a hardware control
    (EncoderElement / SliderElement) that, on every MIDI-driven value
    event, reads the bound param's current value and dispatches show_param.

    param_provider: zero-arg callable returning the bound Parameter (or
      None if currently unbound). Called at fire-time, NOT cached at
      registration -- the binding may change.
    name_provider: optional zero-arg callable returning the display name.
      Defaults to param.name with original_name fallback.
    """
    def _cb(value):
        try:
            param = param_provider()
            if param is None:
                return
            try:
                fmt = param.str_for_value(param.value)
            except Exception:
                try:
                    fmt = repr(param.value)
                except Exception:
                    return
            if name_provider is not None:
                try:
                    nm = name_provider()
                except Exception:
                    nm = getattr(param, "name", None) or getattr(param, "original_name", "?")
            else:
                nm = getattr(param, "name", None) or getattr(param, "original_name", "?")
            self.show_param(nm, fmt, param_id=id(param))
        except Exception:
            pass
    return _cb
```

def update(self):
    # Tear down any prior message listeners FIRST.
    for ctrl, cb in self._param_message_listeners:
        try:
            ctrl.remove_value_listener(cb)
        except Exception:
            pass
    self._param_message_listeners = []

    ChannelStripComponent.update(self)
    # Attach hardware listeners to whatever the framework just bound.
    if self._messenger is None:
        return
    for ctrl in self._gather_owned_controls():
        if ctrl is None:
            continue
        try:
            cb = self._messenger.make_hardware_value_callback(
                (lambda c=ctrl: getattr(c, "_parameter_to_map_to", None)
                                or (c.parameter() if hasattr(c, "parameter") else None)))
            ctrl.add_value_listener(cb)
            self._param_message_listeners.append((ctrl, cb))
        except Exception:
            pass

def _gather_owned_controls(self):
    out = [getattr(self, "_volume_control", None),
           getattr(self, "_pan_control", None)]
    sends = getattr(self, "_send_controls", None)
    if isinstance(sends, tuple):
        for s in sends:
            out.append(s)
    return out
