# Requirements: v1.2 Documentation

**Defined:** 2026-05-02
**Core Value:** Users can install, configure, and operate every shipped controller feature without reading source code.

## v1 Requirements

Documentation deliverables for the user-facing manual. The implementation features themselves are already shipped (v1.0, v1.1, and post-v1.1 commits scoped under v1.2). This milestone only documents them.

### User Manual

- [ ] **DOC-01**: Installation & first-time setup — deploy script to Ableton MIDI Remote Scripts directory (Windows / macOS paths), select in Live's preferences, verify handshake
- [ ] **DOC-02**: Controller layout reference — interactive HTML map (modeled on `example/lp-interactive-map.html`) with mode-repaint covering the three orthogonal mode dimensions (encoder modes per DOC-04, matrix modes per DOC-10, step sequencer overlay per DOC-09) plus modifier overlays (Shift held, Save mode); rich hover tooltips on every control; companion static SVG generated by a Python script for printable/non-interactive fallback
- [ ] **DOC-03**: Toggle/momentary behavior — unified model for Solo, Mute, and Send mode buttons (short-press toggles, ≥400ms acts momentary, fires at press-down)
- [ ] **DOC-04**: 16-macro Pan mode — top encoders → device parameters 1-8, device encoders → 9-16, ring LED feedback, bank navigation on device row only
- [ ] **DOC-05**: Rack macro variations (Ableton-canonical term) — save and recall via Tap Tempo + Nudge buttons, including the Shift+Tap Tempo save-cancel safety on encoder touch
- [ ] **DOC-06**: Ramp encoders — interpolate between rack macro variations using absolute encoder mapping over the visible macro count
- [ ] **DOC-07**: Lock-to-device — Shift+Nudge Back toggles device follow-selection (relocated from Tap Tempo)
- [ ] **DOC-08**: Troubleshooting & known limitations — handshake failures, exclusive-solo bypass, fixed 400ms threshold, hardware constraints (no per-track Send buttons, no Activator/arm)
- [ ] **DOC-09**: Step sequencer — 64-step sequencer overlay engaged via Shift toggle (`_step_sequencer_active` in `ShiftableSelectorComponent`); step grid with bank pages (`set_bank_buttons`), velocity buttons (`set_velocity_buttons`), loop start / loop length controls, lane mute buttons with shifted quantization (`q_step`), follow button. Source: `StepSequencerComponent.py`
- [ ] **DOC-10**: Matrix modes — eight base modes selected by the matrix-mode buttons: Clip Launch (default 5×8 clip grid + Track Stop + Scene Launch), Session Overview (zoom-out navigation), and Note/User Modes 1–6 (six pads-as-MIDI-notes layouts). Includes documenting the **`Matrix_Maps.py` user-editable format**: PATTERN_N (LED colors 0–127), CHANNEL_N (MIDI channel 0–15), NOTEMAP_N (8×8 note-per-cell grid), USE_STOP_ROW_N (whether the bottom row joins the grid), IS_NOTE_MODE_N (Note Mode sends MIDI notes; User Mode does not). Source: `MatrixModesComponent.py`, `Matrix_Maps.py`
